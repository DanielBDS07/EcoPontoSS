EcoPonto SS - Site de reciclagem (PHP + MySQL + Bootstrap, padrão MVC)

COMO RODAR (XAMPP/WAMP)
1. Copie a pasta "reciclagem" para o htdocs (XAMPP) ou www (WAMP).
2. Se o seu MySQL tiver senha, ajuste config/database.php e o instalar.php.
3. Abra http://localhost/reciclagem/instalar.php UMA vez. Ele cria o banco, as tabelas e os
   usuários de teste. Depois apague o instalar.php.
4. Acesse http://localhost/reciclagem/

USUÁRIOS DE TESTE (senha 123456)
- admin@reciclagem.com       -> administrador
- entregador@reciclagem.com  -> entregador já aprovado
- candidato@reciclagem.com   -> entregador pendente (o admin precisa aprovar)
- usuario@reciclagem.com     -> usuário comum

PASTAS (MVC)
- app/models       -> acesso ao banco
- app/services     -> regras de negócio (ColetaService)
- app/controllers  -> controllers
- app/views        -> telas em Bootstrap
- uploads          -> fotos enviadas
- index.php        -> recebe todas as páginas (rotas)

FLUXO DE UMA COLETA
usuário cadastra -> admin aprova ou recusa -> entregador reserva -> entregador marca como coletada
-> entregador registra o recebimento -> concluída
